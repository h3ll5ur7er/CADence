Use CADence's MCP server from other projects: one executable that runs anywhere, without Node, `node_modules` or this repository.

- [x] `npm run build:binary`: a Node single executable application for this platform, `dist/binary/cadence.exe` (or `cadence`), with the program, the geometry kernel's and the constraint solver's WebAssembly and the fonts inside
- [x] On first start the binary unpacks those files into a folder of the temporary directory named after the program's hash, and the kernels, fonts and the views worker ([[CAD-125]]) load from there
- [x] Fonts in Node come from the font package wherever it is installed: the module read them below the working folder, so an MCP server started in another project's folder could not lay out text or picture sheets
- [x] Checked from a folder outside the repository: `--help`, `projects`, a script (sketch, extrude, drawing, PDF, sheet picture), the MCP server (41 tools, a sketch with text, a drawing, a PDF, a picture) and the views worker starting from the unpacked script
- [x] Test: the bundled fonts load whatever the working folder, or from the files given ([[src/core/utilities/text/text.spec.ts]])
- [x] User guide: how to build it and add it to Claude Code ([[User-guide/Automation]])

Done in phase 31 ([[Architecture/Decisions#ADR-50]]). The binary is about 120 MB (Node itself is most of it) and is built for the platform it is built on; Windows warns that its signature is broken, since the Node it copies was signed. Not done: binaries for other platforms from CI, signed (a release job could build them on each runner).
