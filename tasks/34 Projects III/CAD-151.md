title: Libraries shared between projects

---

A library is a project whose components (standard parts, a company's brackets) other projects use without copying: assemblies insert them, and an update of the library reaches every project that uses it, with the version they use recorded.

- [ ] A project can be marked as a library; others refer to it
- [ ] Assemblies insert library components; references keep the library version, updated when asked (or always)
- [ ] Archives and git sync carry the reference (and the library, if asked)
- [ ] MCP: list libraries and insert from them
- [ ] ADR: how references between projects are stored and resolved
- [ ] Test: a library part changes, the assembly that uses it follows
