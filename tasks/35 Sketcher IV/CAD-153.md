Dimensions that show a measured value (in brackets) without driving the sketch; they follow when the sketch changes and can be turned into driving ones.

- [x] A dimension can be driving or a reference; a reference adds no constraint
- [x] Shown in brackets, updated on every solve
- [x] A dimension that would over-constrain is offered as a reference
- [x] Parameters can read a reference value
- [x] Test: a reference dimension follows a changed sketch

Built as a flag on dimensions (`reference`, `name`), solved without and measured after ([[Architecture/Decisions#ADR-54]]). Tests: [[src/core/managers/design/reference-dimensions.spec.ts]], the journey [[e2e/sketcher-4.spec.ts]].
