Dimensions that show a measured value (in brackets) without driving the sketch; they follow when the sketch changes and can be turned into driving ones.

- [ ] A dimension can be driving or a reference; a reference adds no constraint
- [ ] Shown in brackets, updated on every solve
- [ ] A dimension that would over-constrain is offered as a reference
- [ ] Parameters can read a reference value
- [ ] Test: a reference dimension follows a changed sketch
