A group of curves and relations kept as a block (a slot pattern, a logo) and inserted again in other sketches and projects, placed by a point and an angle and scaled, and edited in one place.

- [x] Make a block from a selection; a block has an insertion point
- [x] Insert into any sketch: placed, turned and scaled; constrained as one
- [x] Blocks in a project (and in libraries, [[CAD-151]]); editing a block updates its insertions
- [x] Explode an insertion into plain curves
- [x] Test: a block inserted twice, edited once

A block is a sketch marked `block`; placements are generated geometry like drawings kept as one piece ([[Architecture/Decisions#ADR-54a]]). Placements may name blocks of other components of the project. Sharing blocks with other projects waits for libraries ([[CAD-151]], phase 34): a placement's `document` would then name a library's component. Tests: [[src/core/managers/design/sketch-blocks.spec.ts]], the journey [[e2e/sketcher-4.spec.ts]].
