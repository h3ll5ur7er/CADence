A rib may run up to the next face instead of a set depth; blind holes may end in a drill point (118°).

- [x] Rib: up to the next face in its direction
- [x] Hole: drill point at the bottom of blind holes, 118° by default
- [x] Test: a rib between two walls; a blind hole with a drill point

Done in phase 36: a rib's `extent: 'next'` runs it from its sketch plane to where it first meets the bodies (each way when symmetric), ending on whatever face it meets, and says when part of it meets nothing; blind holes take `drillPoint` and `pointAngle` (118° when empty), a cone below the depth named `f:<hole>:point:<point>`, and hole callouts add "118° point" ([[Architecture/Decisions#ADR-55]]). Journey: `e2e/part-modeling-4.spec.ts`.
