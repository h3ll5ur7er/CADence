An MCP tool that runs a whole script (the scripting API) at once, as the radial engine's agent did through the command line to place dimensions on 26 sheets: loops and calculations without a call per step.

- [x] `run_script`: a script as text, run against the projects with a time limit
- [x] Its output and the documents it changed in the answer
- [x] Sandboxed: the scripting API only, no files outside exports
- [x] Test: a script that makes ten parts in one call

Notes: the script runs in QuickJS compiled to WebAssembly (the Sandbox utility, [[Architecture/Decisions#ADR-60]]), with `cadence` made of stand-ins whose calls go to the real API as JSON ([[src/automation/script.ts]], members listed once in [[src/automation/script-api.ts]]): every call is awaited, members the list leaves out do not exist, `to` paths must lie in the exports folder. Limits: 2 minutes by default (`seconds`, at most 10 minutes), 256 MB. The command line runs each script in a worker thread of its own, so a loop that never waits holds up no other request, and a cancelled call ends the worker. The answer: the returned value, the printed lines, and the documents created, changed or deleted. `run_script` also runs scripts kept with a project and plugin generators (`project`, `generator`, `parameters`); `list_scripts` lists them. Tests: [[src/automation/scripts.spec.ts]], [[src/core/utilities/sandbox/sandbox.spec.ts]].
