The command reference and the user guide as MCP resources, and prompts for common jobs (a part from a sketch, a drawing of a part, an assembly of parts).

- [x] Resources: command reference by topic, user guide pages
- [x] Prompts: a few common jobs with their arguments
- [x] Test: list and read a resource, get a prompt

Notes: `cadence://reference/<topic>` (the topics of `command_reference`, plus `scripts`: the sandboxed scripting API's types) and `cadence://guide/<page>` (the user guide's pages, embedded when the command line is built: `cadence:guide` in [[tools/automation/build.mjs]]). Prompts: `part_from_sketch`, `drawing_of_part`, `assembly_of_parts`, `parts_by_script` ([[src/automation/resources.ts]]); a missing required argument is refused (-32602). The server announces `resources` and `prompts` in its capabilities.
