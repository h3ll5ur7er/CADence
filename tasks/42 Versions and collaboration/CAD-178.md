Several people edit one project at once and see each other's changes and cursors, built on commands and on the merge of [[CAD-176]], over the server of [[CAD-177]].

- [x] ADR: commands over a relay, ordering and conflicts (operational transforms or a CRDT)
- [x] Live changes and presence (who is where) in the editors
- [x] Works offline and catches up
- [x] Test: two browsers edit one sketch at once

Built ([[Architecture/Decisions#ADR-61a]]): the server's relay orders commands (server-sent events read with `fetch`, snapshots, presence); the Design Manager's live session ([[src/core/managers/design/live.ts]]) applies changes here at once, others' in the relay's order with ours run again on top, sends undo as the whole document, catches up after being offline and merges three ways when back from behind the room's snapshot. The component editor goes live by itself for shared projects, shows who is where and others' pointers in a sketch. Tests: [[src/core/managers/design/live.spec.ts]] (one sketch from two sessions at once, offline catch-up, a change that no longer applies, a late joiner, a viewer) and the journey (two browsers, one sketch).
Not done: assemblies and drawings live (they sync through versions); rooms are in the server's memory.
