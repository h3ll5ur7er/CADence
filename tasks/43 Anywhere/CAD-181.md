A short interactive tour on first start, sample projects to open, and links from tools to their User guide pages.

- [x] A tour of the first part (sketch, extrude, export), skippable
- [x] Sample projects on the home page
- [x] Help links from dialogs and tools to the User guide
- [x] Test: the tour runs through, and a sample opens

Notes ([[Architecture/Decisions#ADR-62]], [[User-guide/Getting-started]]):
- The tour ([[src/app/shared/tour.ts]], [[src/app/shared/tour-overlay.ts]]): a step names its target (`data-tour`) and what the user's action brings up; it moves on when that appears. It starts by itself on the first start, never in an automated browser (`navigator.webdriver`): tests opt in by overriding it; the desktop journey marks it as seen. Restart: **Take the tour** on the home page, or the command palette.
- Samples: the shipped templates, listed at the bottom of the home page and opened as projects of one's own. The tour and samples cover what is on this branch; other phases' features join them when merged.
- Help links: `cad-help` with a topic ([[src/app/shared/help-topics.ts]]) in 21 panels and dialogs; `tools/docs/help-links.spec.ts` checks every topic against the User guide's headings.
