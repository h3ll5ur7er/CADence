New users should see what CADence can do. The R-9 radial engine ([[CAD-96]]), the robot arm ([[CAD-182]]) and the Stewart platform ([[CAD-183]]) stayed with us; they now ship with the app beside the templates ([[Architecture/Decisions#ADR-67]]).

- [x] `public/examples`: the three projects as `.cadence` archives, a picture each and an index naming the document each opens at
- [x] The home page's Samples list them first, with their pictures; opening one imports it as a project of one's own at its assembly
- [x] A model larger than the home view is framed when it opens (the arm opened looking at its base)
- [x] `src/automation/examples.spec.ts` opens each with every component, assembly and drawing free of errors; a journey opens the arm from the home page
- [x] User guide and Development page
