Reported by an agent modelling a keyboard enclosure through the MCP server (`cadence.exe mcp`, 2026-10-19/20, projects *KB enclosure* and *KB enclosure simple*), report 3.

`import_file` of a KiCad board STEP with component models (`kicad-cli pcb export step --subst-models`, 6 MB) imports and pictures fine, but an `insert` feature with it is refused: *The imported file has to be read again.* Re-importing with `replace` changes nothing; a board-only STEP (3.6 MB) inserts fine. Inserted into an assembly it is *missing*, and after removing that instance the assembly still lists *kb-pcb: missing*.
