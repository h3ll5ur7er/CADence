Reported by an agent modelling a keyboard enclosure through the MCP server (`cadence.exe mcp`, 2026-10-19/20, projects *KB enclosure* and *KB enclosure simple*), report 6.

A sketch with overlapping rectangles and circles, all its profiles extruded with *join* (or a circle and a rectangle as *new-body*), fails: *The result is not a valid solid.* The sketch also has sliver profiles (0.165 mm²). Separate sketches and extrudes work.

- [x] Selected profiles that touch are joined into one region before extruding
- [x] Test: a circle and an overlapping rectangle, all profiles extruded at once

Done in phase 33: fusing the 15 outlines of the rib sketch in the plane lost most of them (the extrude built only a sliver and a far rib) or gave an invalid tool. When the drawing's area differs from the profiles' or the solid is invalid, each profile is made solid on its own and the solids are fused.
