Reported by an agent modelling a keyboard enclosure through the MCP server (`cadence.exe mcp`, 2026-10-19/20, projects *KB enclosure* and *KB enclosure simple*), report 8.

A 45° helical gear fails the print check (*walls down to 0.001 mm*): where a tooth meets an end face it ends in a knife edge. A chamfer cannot be added afterwards ([[CAD-133]], [[CAD-137]]).

- [x] The gear part takes an end chamfer of its teeth (tip relief)
- [x] Test: a chamfered helical gear passes the wall check

Done in phase 33: the gear part takes `chamfer` (45°, at both ends, measured at the tip). The knife edge of the report was the wall check's: a 45° helical tooth meets the end face at about 47°, which the check now lets pass ([[CAD-143]]).
