`edit_component` answers with the whole component after every call: all project parameters, every sketch with every profile, and every face and edge of every body. In [[CAD-96]] a 4-edge fillet on a link rod returned about 5,000 tokens, a finned cylinder barrel about 4,000, most of it unchanged since the call before; a crankcase with nine cylinder pads will be many times that. Agents run out of context on exactly the large models this server should handle. With gears it stops working at all: adding one 28-tooth gear (648 faces, 1,938 edges, see [[CAD-107]]) produced a 165,000-character answer, which Claude Code refuses to pass on ("exceeds maximum allowed tokens"); the change is made, but the agent cannot see its result.

- [x] `edit_component` returns what changed: the timeline items run (with errors), new or changed sketches and their profiles, and the bodies' face and edge counts
- [x] `get_component` takes filters: a sketch, a body, faces or edges only, names matching a pattern (`f:pocket:*`), or near a point
- [x] Project parameters listed once (`get_component`), not with every edit

**Done (phase 26).** The 28-tooth gear's answer was 165,000 characters; with the smooth teeth of [[CAD-107]] the whole component is about 34,000, and an edit's answer is a few hundred.
