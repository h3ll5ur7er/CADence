`loftTool` ([[src/core/engines/modeling/tools.ts#L229-L250]]) hands each section's outer loop to `BRepOffsetAPI_ThruSections` as it comes from region detection. Each loop starts wherever detection starts it, and sections with different edge counts are matched by OpenCascade from those starting points. A loft from a round shank into airfoil sections, the usual way to make a propeller blade, twists half a turn and pinches in the middle. Found in [[CAD-96]] (Propeller blade).

## Reproduce

Planes offset from YZ at 35, 80, 160, 250, 330 and 380 mm. At 35 mm, a circle of 30 mm (its loop has 2 arcs and starts at angle 0°). At the others, closed splines through 14 points of a NACA 00xx section, chord 70 → 30 mm, turned 50° → 14° (each loop has 14 Béziers and starts at the leading edge, about 210° from the circle's start). A smooth loft through all six sections pinches near the middle of the blade. The same loft without the circle is smooth.

There is no way to influence this from the model: no start point per section, no alignment option.

- [x] Match the sections before lofting: rotate each closed loop to start at the point nearest the previous section's start (or at the same angle around its centroid), and give them the same direction
- [ ] Optionally let the user pick a start point (a sketch point) per section (left for later: [[Open points]])
- [x] Test: circle → airfoil loft has no twist (for example, its side faces' normals turn by less than 90° between sections)

**Done (phase 26)**, without the optional start point: sections are lined up ([[src/core/engines/modeling/sections.ts]]) and the kernel's own matching is off. The test checks the blade's cross-sections between the shank and the first section: no pinch. A start point per section is left for later ([[Open points]]).
