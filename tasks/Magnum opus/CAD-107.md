`gearOutline` ([[src/core/engines/modeling/parts.ts#L46-L76]]) builds a gear as one polygon: each flank is 8 straight pieces, the root between teeth 4 chords, so every tooth has 23 flat faces. A 28-tooth gear (module 1.5) has 648 faces and 1,938 edges; a 70-tooth cam gear has about 1,600 faces. Found in [[CAD-96]], where a gear train of six gears makes every later boolean, mesh and answer heavy: the `edit_component` answer for the single 28-tooth gear was 165,000 characters ([[CAD-102]]). The flanks are also not true involutes, so the faceting shows on prints of larger gears.

- [x] Flanks as smooth curves (a B-spline through the involute points, or the involute evaluated as a curve), the root as arcs of the root circle, with a root fillet
- [x] A spur gear then has about 4–6 faces per tooth
- [x] Rack teeth the same way (straight flanks are fine, the root and tip as single lines)

**Done (phase 26).** Up to 41 teeth (20°) a tooth has eight faces: flanks, tip, root, two fillets and two short radial pieces below the base circle; from 42 teeth on, four. Flanks are quintic Béziers within 0.003 module of the involute. The 28-tooth gear has 228 faces instead of 648.
