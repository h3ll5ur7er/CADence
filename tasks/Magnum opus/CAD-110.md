title: Exploded views cannot move pattern copies

status: done

labels: [assemblies, exploded-views, found-by-CAD-96]

An exploded view step accepts only instances of the assembly; a step naming a pattern copy (`pat_cyl/h1/3`) is refused with "Each step moves instances of this assembly along a direction by a distance." ([[src/core/managers/assembly/commands.ts#L188]]), which does not say what is wrong. In [[CAD-96]] the nine cylinder heads, eighteen plugs, nine pushrods, intake pipes and exhaust stubs are one original each plus a circular pattern of 8, and the three blades a pattern of 2, as patterns are meant to be used; the radial exploded view (each cylinder's parts outwards along its own direction) cannot be built without giving up the patterns.

- [x] Steps may name pattern copies (their ids as `get_assembly` and `assembly_properties` list them), each moved along the step's direction
- [x] Optionally: a radial step (each instance moves away from an axis) so a circular pattern explodes in one step
- [x] When a step is refused, name the id that is not an instance

**Done (phase 27)**, with the radial step: steps may name pattern copies (`<pattern>/<instance>/<n>`), and `radial: true` (with an `origin`) moves each part straight away from the axis along the step's direction. A refused step names the id. The exploded view panel lists copies and offers *Away from the axis*.
