Follow-up of [[CAD-102]] for assemblies, found building the radial engine in [[CAD-96]]:

- `edit_assembly` answers with the full definition of every changed instance and joint, plus a `moved` map that repeats the positions. One `set-joint-values` on the crankshaft answered with about 15,000 tokens (27 instances and 28 joints in full); adding nine cam links echoed their 72-point profiles back, about 25,000 tokens.
- `command_reference` is 77,000 characters, more than Claude Code passes on, so an agent never sees it whole; and it refers to `PartSpec`, `planetaryRatios` and `ringGearMesh` without including [[src/core/contracts/parts.ts]], so the part kinds (gear, ring gear, screw, bearing, …) cannot be learnt from the server at all.
- `get_component`'s `near` measures to face centres; a revolved face's centre lies on its axis, so a point on a barrel wall finds nothing within 3 mm.

- [x] `edit_assembly`: per changed joint its values (and errors), per moved instance its new position; full definitions only for what the commands created
- [x] `command_reference` by topic (`component`, `assembly`, `parts`, …) and including the parts contract
- [x] `near` measures the distance to the face or edge itself

**Done (phase 27).** `edit_assembly` answers with what the commands created (cam profiles and study keys counted, not listed), the joints whose values or errors changed, the instances that moved and the ids of other things changed. `command_reference` takes a topic: commands, sketch, features (with the parts contract), document, assembly; each under 25,000 characters. `near` measures to the faces' triangles and the edges' segments.
