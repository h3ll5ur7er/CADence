Asked to add technical drawings of every component of the radial engine ([[CAD-96]], 30 documents), I found no way to do it as an agent. The app has drawings ([[User guide/Drawings]]: sheets with title blocks, views, sections and details, dimensions, notes, centre marks and lines, hole callouts, parts lists, balloons, PDF and DXF), and the core has their commands (`set-sheet`, `set-title-block`, `add-view`, `add-annotation`, … in [[src/core/managers/drawing/drawing-manager.ts]]) and exports ([[src/core/managers/drawing/exports.ts]]). None of it reaches the MCP server or the scripting API:

- `create_document` takes only `component` or `assembly` ([[src/automation/mcp.ts#L202]]).
- No tool edits, lists, pictures or exports a drawing; `export_imported` handles imported DXF/SVG only, `export_component` a sketch or flat pattern.
- `command_reference` has no drawing topic; the scripting API has no `cadence.drawing(id)`, and the CLI no drawing export.

An agent also needs to see what it can dimension. Annotations anchor to a view's points, circles and lines by persistent name ([[src/core/contracts/drawing.ts#L57-L61]]), so it needs a list of the visible edges and circles of each view, with their names and where they lie on the sheet, plus a picture of the sheet to check the layout.

- [x] `create_document` with kind `drawing`
- [x] `edit_drawing`: the drawing commands (sheet, title block, views with section and detail, annotations), answering with what changed, views placed (their box on the sheet) and annotations whose geometry is missing
- [x] `get_drawing`: sheet, views and annotations, and for a view its visible points, circles (centre, diameter) and lines with persistent names and sheet positions, filterable (`view`, `kind`, `near`)
- [x] `render_picture` of a drawing (the sheet as the PDF shows it), with zoom onto a view
- [x] `export_drawing`: PDF and DXF
- [x] `command_reference` topic `drawing`; the scripting API and CLI get the same (`cadence.drawing(id)`, `cadence export <drawing> --format pdf`)
- [x] Test: through the MCP server, a drawing of a component with three views, a section, diameter and linear dimensions and a hole callout, exported to PDF

Done in phase 29 ([[Architecture/Decisions#ADR-48]]): `create_document` makes drawings; `get_drawing` (sheet, views with their boxes, annotations, anchors filtered by view, kind or a sheet point), `edit_drawing` (brief answers: created, changed, removed, placed views, view errors, lost annotations), `undo_drawing` (also redo), `export_drawing` (PDF, DXF) and `render_picture` of a sheet (focus a view id to zoom). The sheet picture is drawn by a 2D renderer with the bundled font, as the PDF shows it. `command_reference` has the topic `drawing`; scripts get `cadence.drawing(id)`; the command line exports and pictures drawings. Test: through the MCP server, a component drawn with three views and a section, a horizontal and a diameter dimension and a hole callout, pictured and exported to PDF and DXF.
