Finishing the radial engine ([[CAD-96]]), the agent found it could not make drawings ([[CAD-123]]). Everything a person does in the app goes through the managers (Project, Design, Assembly, Drawing), so an agent should reach every manager operation through the MCP server and the scripting API too. Compared with the managers' interfaces, the MCP server lacked:

- **Drawings** ([[CAD-123]]): creating, editing, listing, picturing and exporting them.
- **Projects:**
  - renaming, deleting and duplicating projects;
  - duplicating documents;
  - templates;
  - project archives (`.cadence`, with history), out and in;
  - replacing an imported file.
- **Versions:** recording, listing (project and document), restoring a document, and naming versions.
- **Git:** setting a remote, syncing, and opening a project from a repository.
- **Components:**
  - redo;
  - measuring;
  - the strength check;
  - a sketch's freedom and suggested relations;
  - inserting a DXF, SVG or picture into a sketch;
  - broken references with their candidates;
  - the configuration table as CSV, out and in;
  - the HTML viewer.
- **Assemblies:** redo, measuring, the bill of materials as CSV, build instructions (PDF) and the HTML viewer.
- **Pictures:** section views, as the viewer's section plane shows them, and imported 3D files.

Left out on purpose, since they only serve the app's own screen: thumbnails, drag previews (`previewDrag`, `previewJoint`), recorded videos (agents get `animate_study`), and surface analysis colours.

- [x] Drawings: `create_document` kind `drawing`, `get_drawing`, `edit_drawing`, `undo_drawing`, `export_drawing`, `render_picture` of a sheet ([[CAD-123]])
- [x] Projects: `rename_project`, `delete_project`, `duplicate`, `create_project_from_template`, `export_project` and `import_project`, `import_file` replacing an imported document
- [x] `versions`: list, record, restore, name and unname
- [x] `sync_project` and `open_git` (credentials from the environment, as on the command line)
- [x] Redo for components, assemblies and drawings
- [x] `measure` (components and assemblies), `simulate_component`, `check_sketch` (freedom, suggestions), broken references
- [x] `edit_component` commands `insert-drawing` and `import-configurations`; exports to the HTML viewer and the configuration CSV
- [x] `export_assembly` to the bill of materials (CSV), build instructions (PDF) and the HTML viewer
- [x] `render_picture` with a section plane, and of imported 3D files
- [x] The scripting API and the command line get the same
- [x] Tests through the MCP server for each group

Done in phase 29 ([[Architecture/Decisions#ADR-48]]): every group is a tool or part of one, tested through the MCP server in [[src/automation/automation.spec.ts]] (git with an unreachable repository there; real syncs are tested in the Project Manager). The tools are grouped in [[src/automation/tools/projects.ts]], [[src/automation/tools/models.ts]] and [[src/automation/tools/drawings.ts]]. Build instructions from scripts embed deflated pixels, since Node has no JPEG encoder.
