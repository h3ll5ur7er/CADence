The radial engine's crankcase is one component with two configurations, *Front half* and *Rear half* ([[CAD-96]]). Its drawing can only show the default configuration: `DrawingView` has a `source` but no `configuration` ([[src/core/contracts/drawing.ts]]), unlike an assembly instance. So the rear half (65 mm deeper) has no drawing. The assembly drawing's parts list already names both (*Crankcase (Front half)*, *Crankcase (Rear half)*).

- [x] `DrawingView.configuration` (as on instances): the view shows that configuration's result; the view's panel offers the component's configurations
- [x] The title block can name the configuration (or the sheet adds it to the title)
- [x] Test: two views of one component in different configurations draw different shapes

Done in phase 30 ([[Architecture/Decisions#ADR-49]]): `DrawingView.configuration` names a configuration of the component; the view shows that configuration's result (asked for like an assembly instance's), its hole callouts use the configuration's values, and a configuration that is gone says so. In the editor the add-view menu and the view's properties offer the component's configurations, and the view is named with it (*Right of Crankcase (Rear half)*). The title block keeps its typed title (*Crankcase (Rear half)*, as the agent named it); `edit-view` refuses an unknown configuration and lists the known ones. Tests: [[src/core/managers/drawing/drawing-manager.spec.ts]] (a thin configuration draws a lower view), through the MCP server in [[src/automation/automation.spec.ts]], and the journey in [[e2e/stress-test-findings.spec.ts]].
