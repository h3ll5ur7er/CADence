Dimensioning the radial engine's drawings ([[CAD-96]]) through the MCP server, most of the tokens went into reading `get_drawing`:

- Every call repeats the sheet, the title block, all views with their boxes and all annotations, even when only one view's anchors are asked for.
- Anchor names are persistent names of up to 150 characters (`v:e:f:case:side:ng:l1|f:case:side:ng:l9&e:f:case:side:ng:l1|f:half:start~1&…`), and every one has to be copied back into `edit_drawing` exactly.
- A vertex is listed once for each pair of edges meeting there: the same point at the same place under several names. The crankcase's top view offered 116 anchors, the cam ring's gear teeth over 12,000.
- `near` with a radius returns everything around a point. There is no way to ask for "the circles of this view by radius" or "the extreme points of this view".

After two drawings the agent switched to a script that lists anchors as `index kind x,y r…` and refers to them by index. That made 26 more drawings practical.

- [x] `get_drawing` with `only` (anchors, views, annotations) like `get_component`
- [x] Short anchor handles in answers (an index or a short id stable while the drawing is unchanged), accepted by `edit_drawing` in place of the name
- [x] One anchor per point (the names merged), circles grouped by radius, an `extremes` filter (left, right, top, bottom of a view)
- [x] The view's model point under each anchor (model mm), so an agent can tell which feature it is

Done in phase 30 ([[Architecture/Decisions#ADR-49]]): `get_drawing` lists anchors only when asked for (by view, kind, near, `diameter`, `extremes`; else only the counts per view), `only` picks the parts, and anchors come once per place (a seen one where several names meet), each with a short `ref` (kind letter and a hash of its name, unique in the view), its point in the model (`model`) and circles' `diameter`; circles come largest first. `edit_drawing` takes `{ view, ref }` wherever an anchor goes, and annotations answer with refs (`names: true` for names). Tests: through the MCP server in [[src/automation/automation.spec.ts]].
